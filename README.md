# Small Business Network Architecture

## Overview
This project demonstrates a secure small business network architecture designed using cybersecurity best practices.

The environment includes:
- VLAN segmentation
- DMZ network design
- Firewall policy concepts
- Secure routing practices
- Network isolation strategies

## Security Features
- Segmented internal networks
- Controlled traffic flow
- Perimeter security concepts
- Basic intrusion prevention planning
- Secure administrative access

## Skills Demonstrated
- Networking
- Cybersecurity architecture
- VLAN implementation concepts
- Firewall policy planning
- Technical documentation
- Infrastructure design

## Technologies & Concepts
- VLANs
- TCP/IP Networking
- Firewalls
- DMZ Architecture
- Routing & Switching
- Network Segmentation

## Purpose
This project was created to strengthen practical networking and cybersecurity knowledge while building a professional portfolio.
